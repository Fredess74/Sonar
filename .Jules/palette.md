## 2024-05-18 - [Timeline Keyboard Navigation and ARIA Current]
**Learning:** In the Sonar application, interactive timeline steps were previously implemented using `div` elements with `onClick` handlers, which made them inaccessible to keyboard users and screen readers. Furthermore, the selection state of the timeline step was not programmatically communicated.
**Action:** Always use semantic `<button type="button">` for interactive list items. Add utility classes `w-full text-left focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-sonar-accent` to maintain layout while providing explicit keyboard focus styles. Use `aria-current="step"` (or similar appropriate ARIA attributes) to dynamically indicate the active element in the list. Ensure consistency between desktop (`Sidebar`) and mobile (`BottomSheet`) responsive views.
