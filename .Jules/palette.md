## 2025-07-04 - [Search Island focus-within Pattern]
**Learning:** For glassmorphic compound components like the Search Island that contain an input, use `focus-within` on the parent container (and `group-focus-within` on sibling icons) to provide a unified focus state across the entire group, improving visibility and clear interaction feedback without requiring JavaScript.
**Action:** Always check compound input fields for missing parent-level focus indicators.
