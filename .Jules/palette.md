## 2024-03-16 - Timeline Interaction Accessibility Pattern
**Learning:** In the Sonar app, replacing interactive list `<div>` wrappers with semantic `<button type="button">` elements (while retaining custom click handlers and class-based layouts) reveals gaps in keyboard navigation. Due to the custom styling, the default focus rings are lost. It is critical to enforce explicit `focus-visible` outline styles alongside `aria-current` for proper accessibility across responsive views like `Sidebar` and `BottomSheet`.
**Action:** Always implement interactive list items (such as timeline steps or selectable cards) as `<button type="button">` with `w-full text-left`, `cursor-pointer`, `aria-current` for selected states, and explicit `focus-visible:outline-none focus-visible:ring-2` styles to ensure visible focus and screen reader compatibility.
