## 2024-04-12 - [Accessible Interactive Timeline Sequences]
**Learning:** Interactive sequence items (like timeline steps) that function as lists but contain complex clickable content present an accessibility challenge when implemented as simple `div` tags. Using a semantic `<button type="button">` structure correctly scopes the interaction but requires applying specific layout utilities (e.g., `w-full text-left`) to prevent default button styling from breaking the UI. Additionally, marking the active step with `aria-current="step"` ensures screen readers correctly announce progress through the sequence.
**Action:** When creating navigable sequences or timeline steps in React, default to using `<button type="button">` with `aria-current="step"` for the active item. Avoid `div` wrappers with `onClick` handlers for these primary interactive elements to maintain semantic meaning and improve screen reader experiences.
