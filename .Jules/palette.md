## 2026-03-21 - [Interactive Lists & Input Accessibility]
**Learning:** In complex React applications, using `div` elements for interactive list items (like timeline steps) without appropriate roles and attributes hinders accessibility. Utilizing semantic `<button type="button">` with `aria-current` for selected states and `w-full text-left` ensures proper interaction models. Additionally, raw unlabelled input elements (like `textarea` in modals or standalone search inputs) must have explicit `aria-label` attributes for screen readers, while compound inputs (like an icon + input "Search Island") should use `focus-within` on the container to display focus rings appropriately instead of relying on the native input outline.
**Action:** Always favor semantic `<button>` tags over `<div>` with `onClick` for interactive elements. Ensure form inputs that visually lack labels explicitly define `aria-label`, and use `focus-within` for styling complex compound input containers.
